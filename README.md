# sdvProject
## To install and run our system:
1. Install Python version 3.x on your computer.
2. Verify Tkinter is included with your Python installation by running “python -m
tkinter” in your terminal. If a window appears, Tkinter is installed.
3. Download project files from our github.
4. Open using a code editor and run the main file, or run directly from your terminal.
5. Navigate through the GUI to view available rooms, create and change reservations,
and more.
